# Machine Learning Model Comparison and Hyperparameter Tuning

## Project Overview
This project focuses on training, comparing, and evaluating multiple supervised machine learning classification models using the Breast Cancer Wisconsin dataset.

## Dataset
- Breast Cancer Wisconsin Dataset
- 569 samples
- 30 input features
- Binary classification

## Machine Learning Models
1. Logistic Regression
2. Random Forest
3. Gradient Boosting
4. Support Vector Machine (SVM)

## Data Preprocessing
- Train-Test Split
- Feature Scaling using StandardScaler

## Hyperparameter Optimization
- GridSearchCV
- 5-Fold Cross-Validation
- F1-Score Optimization

## Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix
- ROC-AUC Curve

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Project Files
- `ML_Model_Comparison_Tuning.ipynb` – Complete implementation
- `best_ml_model.pkl` – Saved model
- `scaler.pkl` – Saved feature scaler

## Conclusion
Multiple supervised machine learning models were trained and evaluated. Hyperparameter tuning was performed to improve model performance, and the best-performing model was identified based on the F1-score.
